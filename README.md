# 🏝️ Treasure Island Adventure Game

A beginner-friendly, text-based adventure game built using Python. Players make decisions throughout the game to explore Treasure Island and search for hidden treasure.

## 💻 About the Project

Treasure Island is an interactive Python game where players choose different paths that determine whether they find the treasure or reach a game-over ending.

I completed this project while working through the **100 Days of Code: The Complete Python Pro Bootcamp**. This project helped me practice conditional statements, logical operators, and handling user input.

## 🛠️ Skills Practiced

- Python
- Variables
- User input with `input()`
- Conditional statements (`if`, `elif`, `else`)
- Nested conditional statements
- Comparison operators
- String manipulation
- Logical thinking and decision-making

## 🎮 How It Works

The program:

1. Welcomes the player to Treasure Island.
2. Presents the player with different choices.
3. Uses conditional statements to determine what happens next.
4. Allows the player to continue or reach a game-over ending based on their decisions.
5. Determines whether the player successfully discovers the treasure.

## ▶️ How to Run

Make sure Python is installed, then run:

`python treasure_island.py`

Follow the prompts in the terminal and make your choices to see whether you can find the treasure!
